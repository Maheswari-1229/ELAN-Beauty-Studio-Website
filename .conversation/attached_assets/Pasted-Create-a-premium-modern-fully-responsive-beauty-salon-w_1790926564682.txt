ANIMATION SYSTEM
==================================================

Use a consistent animation system throughout the website.

Page-load animation:
- Fade in
- Slight upward movement

Scroll animations:
- Use Intersection Observer or Framer Motion whileInView.
- Sections should animate only once when entering viewport.

Preferred animation:
opacity: 0 → 1
transform: translateY(30px) → translateY(0)

Image animations:
opacity: 0 → 1
scale: 0.95 → 1

Card hover:
translateY(-8px)
transition: 300ms

Button hover:
translateY(-2px)
subtle shadow

Image hover:
scale(1.05)

Navigation:
animated underline

Do not animate every single element aggressively.
